# Codebase Spec Synchronization

Inspect the repository before editing docs.

Produce:

1. implementation inventory;
2. endpoint/model/page inventory;
3. authentication and authorization map;
4. state transition map;
5. integration map;
6. test coverage observations;
7. spec/code conflicts;
8. missing requirements;
9. updated specifications;
10. unresolved product decisions.

Observed code is not automatically approved product intent.

Mark uncertain behavior as `IMPLEMENTATION NOTE`, `ASSUMPTION`, or `OPEN QUESTION`.
